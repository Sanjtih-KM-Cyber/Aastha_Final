Aastha is an open-source Wellness Companion designed to support mental clarity for students facing academic pressure and professionals dealing with career burnout. Built with React and the Gemini API, it provides a secure, anonymous, and judgment-free space to vent, reflect, and grow.

## Key Features

*   **🧠 Emotional Intelligence Engine:** Tracks mood patterns and builds resilience.
*   **🎓 Student Support:** Specialized modules for exam stress and hostel loneliness.
*   **💼 Professional Wellness:** Tools for work-life balance and decompressing after office hours.
*   **🔒 Zero-Knowledge Privacy:** Chats are anonymous and encrypted.
*   **🤝 Saha Alliance:** Integrated "Human Layer" to connect with wellness experts (Coming Soon).

## Tech Stack

*   **Frontend:** React.js, Tailwind CSS
*   **AI Core:** Google Gemini API (Context-aware emotional analysis)
*   **Deployment:** Vercel / Render

## Installation Guide

To get a local copy up and running follow these simple steps.

1.  Clone the repo
    ```sh
    git clone https://github.com/your_username_/Project-Name.git
    ```
2.  Install NPM packages
    ```sh
    npm install
    ```
3.  Start the application
    ```sh
    npm start
    ```
